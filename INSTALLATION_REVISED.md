## How to Get It

### Download & Install (5 minutes)

**Step 1: Download the Plugin**

1. Go to [Gumroad: Podcast Production Suite](https://gumroad.com/sloburnmedia) and purchase the subscription
2. After purchase, download `podcast-production-suite-v1.4.3.plugin`
3. Save it to your Downloads folder

*Or download directly from [GitHub Releases](https://github.com/Huffman3/Podcast-Production-Suite/releases) if you prefer*

**Step 2: Install in Claude Desktop**

1. Open **Claude Desktop** (download here if you don't have it: https://claude.ai/download)
2. In the top-right menu, click the three dots (**⋯**)
3. Select **Settings** → **Plugins**
4. Click **Install Plugin**
5. Select `podcast-production-suite-v1.4.3.plugin` from your Downloads folder
6. Click **Install**

Claude will extract and register all commands, artifacts, and skills automatically.

**Step 3: Verify Installation**

In Claude, type:
```
/setup
```

You should see the **Suite Hub** open with a guided overview of all tools. If this loads, you're good to go.

## If Installation Doesn't Work

**If `/setup` doesn't appear:**

1. **Restart Claude Desktop** (quit completely, then reopen)
2. **Check Downloads folder** — Make sure `podcast-production-suite-v1.4.3.plugin` is there
3. **Re-run the installer** — Go back to Settings → Plugins → Install Plugin and select the file again
4. **Still stuck?** Email support@sloburnmedia.com with:
   - Your operating system (Mac/Windows)
   - Your Claude Desktop version (check Settings)
   - Screenshot of what you see

We'll get you up and running.

## How Commands + Dashboards Work Together

Think of it this way:

**Commands (slash commands)** are the fast workflow tools. Type `/research`, follow the steps, get a .docx file.

**Dashboards (artifacts)** are the visual organizers. Open them, explore data, make decisions.

### Example Workflow: Research a New Case

**Day 1:**
- Type `/research` → Follow the steps → Provide case name and sources
- Get a .docx research brief → Save it

**Day 7:**
- Open the **Production Pipeline** dashboard
- See your case's progress visually
- Drag it to the next stage (e.g., "Research Complete" → "Ready to Script")
- Check what's ready to record next

The command *creates*. The dashboard *organizes*.
