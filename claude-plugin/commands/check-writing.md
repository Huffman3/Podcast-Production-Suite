Check any text for AI-sounding language and rewrite it to sound human and authentic.

1. Read the text the user has provided (or ask them to paste it if none was given)

2. Identify AI-sounding patterns:
   - Hedging language: "it could be argued," "one might say," "somewhat,"  "rather," "quite"
   - Corporate phrasing: "delve," "leverage," "harness," "robust," "landscape," "utilize," "realm," "transformative," "game-changer," "seamless," "testament"
   - Hollow openers: "It's important to note," "In today's digital age," "Furthermore," "Moreover," "In conclusion," "Let that sink in," "At the end of the day," "It goes without saying"
   - Over-explaining: Explaining obvious details, repeating the same point
   - Passive voice overuse: Too many "is/was" constructions instead of active verbs
   - Filler intensifiers: "incredibly," "significantly," "notably," "undeniably," "undoubtedly"
   - Staccato constructions: "No X. No Y." or "It's not X, it's Y."

3. Rewrite the text to sound like a real person talking:
   - Direct and specific, not hedged or qualified
   - Active voice where possible
   - Conversational tone—like texting a friend, not giving a speech
   - Contractions are welcome
   - Uneven paragraphs are fine
   - Show, don't tell—use specific details from the case, not generalizations

4. Present the rewrite side-by-side with a brief note on the key changes made

5. Ask if the user wants any further adjustments
