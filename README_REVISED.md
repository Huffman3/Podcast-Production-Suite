# Podcast Production Suite for Claude

**v1.4.3** — The complete podcast production toolkit built into your AI.

A Claude Desktop plugin that handles **research → scripting → guest workflows → publishing** for any podcast.

---

## What's Included

- **10 Skills** — Research, strategy, outreach, fact-checking, transcription, QA, and publishing
- **10 Interactive Dashboards** — Suite Hub, Production Pipeline, Guest CRM, Anti-AI Checker, Research Agent, and more
- **5 Slash Commands** — `/setup`, `/research`, `/transcribe`, `/check-writing`, `/newsletter`

---

## Features

- **Deep Research** — Case research with sources, timeline, and episode outline
- **Script Quality** — Fact-check and audit for AI-sounding language before recording
- **Guest Workflows** — Draft outreach emails and build interview prep packets
- **Publishing** — Generate show notes, subscriber emails, and social clips
- **Production Tracking** — Manage cases from discovery through publishing
- **Performance Analytics** — Monitor downloads, revenue, and listener trends
