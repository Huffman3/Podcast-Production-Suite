# Podcast Production Suite for Claude Cowork

**v1.4.3** — The complete podcast production toolkit built into your AI.

A Claude Cowork plugin that handles **research → scripting → guest workflows → publishing** for any podcast.

## What's Included

- **10 Skills** — Research, strategy, outreach, fact-checking, transcription, QA, and publishing
- **10 Interactive Dashboards** — Suite Hub, Podcast Research Agent, Production Pipeline, Guest CRM, Anti-AI Checker, Setup Wizard, Marketing Newsletter, Episode Performance, Monthly Revenue, Sponsorship Tracker
- **5 Slash Commands** — `/setup`, `/research`, `/transcribe`, `/check-writing`, `/newsletter`

## Features

- **Research** — Deep-dive case research with sources, timeline, and SCQA episode outline
- **Script Quality** — Fact-check scripts and audit for AI-sounding language before recording
- **Guest Workflows** — Draft cold outreach emails and build interview prep packets
- **Publishing** — Generate show notes, subscriber emails, and social media clips
- **Production Tracking** — Manage cases from discovery through publishing
- **Revenue Tracking** — Monitor sponsorships, downloads, and earned revenue

## Requirements

- Claude Desktop App (free or Pro) — [Download](https://claude.ai/download)
- Cowork mode (research preview access)
- macOS 12+ or Windows 10/11

## Installation

1. Download `podcast-production-suite-v1.4.3.plugin` from the [Releases](https://github.com/Huffman3/podcast-production-suite/releases) page
2. Open Claude Desktop → Cowork mode
3. Go to Plugin Settings → Install Plugin
4. Select the `.plugin` file
5. Type `/setup` to open the hub

[Full installation guide](./INSTALLATION.md)

## Quick Start

Once installed, try these commands:

| Command | What it does |
|---------|------------|
| `/setup` | Open the plugin hub with all available tools |
| `/research` | Start a new case research packet |
| `/transcribe` | Convert MP3 to timestamped transcript |
| `/check-writing` | Audit text for AI-sounding language |
| `/newsletter` | Turn an episode into a subscriber email |
